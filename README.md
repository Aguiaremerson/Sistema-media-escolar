# Sistema de Cálculo de Média Escolar

Projeto desenvolvido em Python para calcular a média de um aluno e informar se ele foi aprovado ou reprovado.

## 📌 Funcionalidades
- Recebe notas do aluno
- Calcula a média
- Informa se está:
  - ✅ Aprovado
  - ❌ Reprovado

## 🛠 Tecnologias utilizadas
- Python
- Lógica de programação
- Estruturas condicionais (if/else)

## 🎯 Objetivo
Praticar lógica de programação e tomada de decisão em Python.
